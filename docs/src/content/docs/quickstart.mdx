### 1. Start Pivot

<Tabs>
  <TabItem label="Local shell">
    **Best for:** querying an object store based datastore directly without running a server or
    installing `psql`.

    Install the Pivot CLI on Linux:

    ```sh
    curl https://pivotlake.io | sh
    ```

    Then open a datastore from its location in Amazon S3 or Google Cloud
    Storage. For S3, export your AWS credentials and region first:

    ```sh
    export AWS_ACCESS_KEY_ID=your-access-key-id
    export AWS_SECRET_ACCESS_KEY=your-secret-access-key
    export AWS_REGION=us-east-1

    pivot open s3://my-bucket/pivot-data
    ```

    For Google Cloud Storage, log in with Application Default Credentials
    first:

    ```sh
    gcloud auth application-default login

    pivot open gs://my-bucket/pivot-data
    ```

    Pivot opens an interactive SQL prompt. The data remains in your bucket
    after you exit with `\q`. See the [CLI reference](/docs/reference/cli/) for
    options, [storage credentials](/docs/reference/cli/#object-store-credentials),
    and shell commands.
  </TabItem>

  <TabItem label="Docker">
    **Best for:** launching a server with minimal setup.

    Start the server with the datastore's location in Amazon S3 or Google
    Cloud Storage. For S3, pass your AWS credentials and region:

    ```sh
    docker run --rm --name pivot \
      -p 5432:5432 \
      -e PIVOT_DATASTORE=s3://my-bucket/pivot-data \
      -e AWS_ACCESS_KEY_ID=your-access-key-id \
      -e AWS_SECRET_ACCESS_KEY=your-secret-access-key \
      -e AWS_REGION=us-east-1 \
      pivotlake/pivot:latest
    ```

    For MinIO or another S3-compatible service, also add
    `-e AWS_ENDPOINT_URL=http://minio:9000`.

    For Google Cloud Storage, mount a service-account key file and point
    `GOOGLE_APPLICATION_CREDENTIALS` at it:

    ```sh
    docker run --rm --name pivot \
      -p 5432:5432 \
      -e PIVOT_DATASTORE=gs://my-bucket/pivot-data \
      -e GOOGLE_APPLICATION_CREDENTIALS=/etc/pivot/gcs-key.json \
      -v "$PWD/gcs-key.json:/etc/pivot/gcs-key.json:ro" \
      pivotlake/pivot:latest
    ```

    The image generates a metastore for the location on startup, while the
    datastore itself remains in your bucket after the container exits. In a
    second terminal, connect with any Postgres client:

    ```sh
    psql -h 127.0.0.1 -p 5432 -U pivot
    ```
  </TabItem>

  <TabItem label="Linux server">
    **Best for:** a persistent production database endpoint for applications, BI tools,
    and other Postgres clients.

    Install Pivot from the Debian or Ubuntu package repository:

    ```sh
    sudo apt-get update
    sudo apt-get install -y ca-certificates curl gnupg
    curl -fsSL https://packages.pivotlake.io/keys/pivotlake-archive-key.asc |
      sudo gpg --dearmor --yes -o /usr/share/keyrings/pivotlake-archive-keyring.gpg

    ARCH=$(dpkg --print-architecture)
    echo "deb [signed-by=/usr/share/keyrings/pivotlake-archive-keyring.gpg arch=${ARCH}] https://packages.pivotlake.io/deb stable main" |
      sudo tee /etc/apt/sources.list.d/pivotlake.list
    sudo apt-get update
    sudo apt-get install -y pivot
    ```

    Use `testing` instead of `stable` in the repository line to receive release
    candidates. The package starts Pivot immediately and enables it at boot.
    Check the service:

    ```sh
    sudo systemctl status pivot
    ```

    Then connect with any Postgres client:

    ```sh
    psql -h 127.0.0.1 -p 5432 -U pivot
    ```

    The package serves a local datastore. To store data in S3 or Google Cloud
    Storage instead, edit `/etc/pivot/config.yaml` as described in
    [Datastores & storage credentials](/docs/reference/server/datastores/).
  </TabItem>
</Tabs>

### 2. Load data

Run the following SQL in the local shell or connected Postgres client:

```sql
CREATE TABLE events (
  id BIGINT,
  name TEXT,
  ts TIMESTAMP
);

INSERT INTO events VALUES
  (1, 'signup', now() - interval '2 hours'),
  (2, 'purchase', now() - interval '1 hour'),
  (3, 'signup', now());
```

To start from existing Parquet files instead, use
[`with_pre_existing_parquets`](/docs/reference/statements/create-table/#adopt-existing-parquet-files).

### 3. Query

```sql
SELECT name, count(*)
FROM events
WHERE ts >= now() - interval '1 day'
GROUP BY name
ORDER BY 2 DESC
LIMIT 10;
```

You should see two `signup` events and one `purchase` event.

### Build from source

To build the same executable from the repository:

```sh
cargo build --release -p bin --bin pivot
```

Run the local shell directly from the build output:

```sh
./target/release/pivot open ./pivot-data
```

To run a server from the build output, copy
[`bin/config.example.yaml`](https://github.com/pivotlake/pivot/blob/main/bin/config.example.yaml),
adjust its datastore locations, and start Pivot with:

```sh
./target/release/pivot server --config pivot.yaml
```
