Pivot is a high-performance analytics engine that runs on open data formats.
It delivers low-latency queries and high concurrency without replicating data
into a dedicated database or proprietary format.

```sh
curl https://pivotlake.io | sh
```

See the [documentation](https://pivotlake.io/docs) to get started.
